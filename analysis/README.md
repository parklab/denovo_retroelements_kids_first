
# Analysis code/scripts, notebooks, and results 

## Target-site-duplication sequence extraction code and extracted sequences
Folder `extract_TSD_seq` contains the code to extract the target-site-duplication sequence and the extracted sequences of each insertion.

## Cleavage site sequence and frequency
Folder `cleavage_sites` contains the scripts and output of the cleavage sites.

## Detailed de novo retroelement insertion information
Folder `separate_mosaic_germline_GMM` contains the notebook to predict the mosaic de novo retroelement insertion from the insertion VAF with a Gaussian Mixture Model.

## De novo rate estimation
Folder `denovo_rate` contains the notebook to estimate the de novo rate.

## Enrichment analysis
Folder `enrichment_analysis` contains the notebooks for confidence interval and p-value calculation, as well as the logo plot generation. Subfolder `code_simulation_for_background_model` contains the python code for background model simulation.

## Lost-of-function intolerant gene 
Folder `pLI_calculation` contains the notebook to extract the pLI value of each gene.
